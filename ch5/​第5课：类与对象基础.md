### 第一部分：理论基础 (45 分钟)

#### 1. `class` 与 `struct` 的唯一区别

在C++中，`class` 和 `struct` 在能力上几乎是完全等价的（都可以有构造函数、方法、继承等），它们唯一的区别在于**默认的访问权限**：

- `**struct`：** 默认所有成员是公开的（Public）。在现代C++工程中，`struct` 通常仅用于定义“纯数据集合”（Plain Old Data, POD），例如三维空间中的 `Point3d` 或巡检任务中的 `BoundingBox`，里面只有数据，没有复杂的内存管理逻辑。
- `**class`：** 默认所有成员是私有的（Private）。用于定义具有复杂内部状态和需要严格控制资源的实体，例如 `Tensor`、`CameraStream` 等。

#### 2. 访问控制修饰符

这是面向对象“封装”特性的体现。通过隐藏内部细节，我们能防止外部调用者写出危险的代码（比如不小心手动 `delete` 了一个正在使用的指针）。

- `**public` (公开)：** 类的外部接口。外界只能通过这些公开的方法来与对象交互。
- `**private` (私有)：** 类的内部状态（如裸指针、容量大小等）。只有类自身的方法可以访问，外部绝对不可见。
- `**protected` (受保护)：** 本类及其子类可以访问，为后续的继承（第7课）做准备。

#### 3. 构造函数与析构函数（结合 RAII 思想）

这是C++相比Python在面向对象上最根本的优势之一。

- **构造函数 (Constructor)：** 类似于Python的 `__init__`。对象创建时自动调用。此时应完成**资源获取**（如使用 `new` 申请堆内存、打开文件、锁定互斥量）。
- **析构函数 (Destructor)：** 类似于Python的 `__del__`，但**具有绝对的确定性**。C++中不需要等待垃圾回收器的光顾，只要对象离开其所在的作用域（如大括号 `{}` 结束），析构函数就会立刻、必定被调用。在这里执行 `delete` 释放内存。

**RAII (Resource Acquisition Is Initialization) 的闭环：**
将原始的堆内存指针隐藏在类的 `private` 区域，利用构造函数申请，利用析构函数释放。这样，调用者只需在栈上创建一个对象，完全不需要手动写 `delete`，彻底消灭内存泄漏。

#### 4. 成员初始化列表 (Initializer List)

这是C++特有的语法，用于在进入构造函数体之前，直接初始化成员变量。

**低效写法（类似Python风格的赋值）：**

```cpp
class MyClass {
private:
    int size_;
public:
    MyClass(int s) {
        size_ = s; // 此时 size_ 其实已经被默认初始化了一次，这里是第二次赋值
    }
};

```

**高效写法（使用初始化列表）：**

```cpp
class MyClass {
private:
    int size_;
public:
    // 冒号后面就是初始化列表，直接就地构造，跳过默认初始化阶段
    MyClass(int s) : size_(s) {} 
};

```

在处理包含大规模自定义对象的类时，初始化列表能避免极其昂贵的“先默认构造，再拷贝赋值”的性能损耗。此外，如果类成员包含引用 (`&`) 或常量 (`const`)，则**必须**使用初始化列表。

### 第二部分：实操实验 (75 分钟)

我们将运用 RAII 思想，从零封装一个极简版的 `Tensor` 类。为了专注这节课的核心概念，我们在加法实现上采用原地修改（In-place addition）的方式，以避免下节课才涉及的“深拷贝与返回值分配”问题。

#### 1. 编写类的声明与实现

创建一个文件 `tensor.cpp`。

```cpp
#include <iostream>
#include <stdexcept>

class Tensor {
private:
    // 隐藏内部细节，防止外部随意修改指针或大小
    float* data_;
    size_t size_;

public:
    // 1. 构造函数与成员初始化列表
    // 负责在堆上分配资源
    Tensor(size_t s) : size_(s), data_(new float[s]) {
        std::cout << "[Constructor] Tensor created, allocated " 
                  << size_ * sizeof(float) << " bytes on Heap." << std::endl;
        // 简单初始化为 0
        for (size_t i = 0; i < size_; ++i) {
            data_[i] = 0.0f;
        }
    }

    // 2. 析构函数 (名称前加 ~)
    // 负责在对象生命周期结束时清理资源
    ~Tensor() {
        delete[] data_; // 释放堆内存
        std::cout << "[Destructor] Tensor destroyed, memory freed." << std::endl;
    }

    // 3. 公开的接口：获取大小
    size_t getSize() const { 
        return size_; 
    }

    // 4. 公开的接口：设置数据
    void setValue(size_t index, float val) {
        if (index >= size_) {
            throw std::out_of_range("Index out of bounds!");
        }
        data_[index] = val;
    }

    // 5. 公开的接口：打印数据
    void print() const {
        std::cout << "Tensor data: [ ";
        for (size_t i = 0; i < size_; ++i) {
            std::cout << data_[i] << " ";
        }
        std::cout << "]" << std::endl;
    }

    // 6. 公开的接口：简单的原地加法 (将另一个 Tensor 的数据加到自己身上)
    // 注意这里按常量引用传递 (const Tensor&)，避免昂贵的拷贝！
    void addInplace(const Tensor& other) {
        if (this->size_ != other.size_) {
            throw std::invalid_argument("Tensor sizes must match for addition!");
        }
        for (size_t i = 0; i < size_; ++i) {
            // this 是指向当前对象的指针
            this->data_[i] += other.data_[i]; 
        }
    }
};

```

#### 2. 编写主程序调用逻辑

继续在同一个文件中编写 `main` 函数，观察对象的生命周期。

```cpp
int main() {
    std::cout << "--- Program Start ---" << std::endl;

    {   // 使用大括号创建一个局部作用域
        std::cout << "Entering local scope..." << std::endl;

        // 在栈上创建 Tensor 对象，底层会自动在堆上分配数组
        Tensor t1(5); 
        Tensor t2(5);

        // 初始化数据
        for (size_t i = 0; i < t1.getSize(); ++i) {
            t1.setValue(i, 1.0f);
            t2.setValue(i, i * 2.0f); // 0, 2, 4, 6, 8
        }

        std::cout << "Before addition:" << std::endl;
        t1.print();

        // 执行原地加法
        t1.addInplace(t2);

        std::cout << "After addition:" << std::endl;
        t1.print();

        std::cout << "Leaving local scope..." << std::endl;
    } // 离开作用域，t1 和 t2 将自动调用析构函数，安全释放堆内存！

    std::cout << "--- Program End ---" << std::endl;
    return 0;
}

```
